# RinconadaClub-System
Sistema de Gestión de Socios desarrollado en C# y SQL Server para Rinconada Country Club

## Descripción
Proyecto académico desarrollado para optimizar la gestión administrativa de Rinconada Country Club mediante una aplicación de escritorio integrada con base de datos.

## Funcionalidades
- Gestión de socios
- Gestión de pagos
- Gestión de reservas
- Gestión de invitados
- Emisión de carnets
- Generación de reportes
- Auditoría de operaciones

## Tecnologías utilizadas
- C#
- SQL Server
- Programación Orientada a Objetos (POO)
- UML

## Estructura del repositorio
- CodigoFuente: código fuente de la aplicación.
- Scripts: scripts de base de datos SQL Server.
- Documentacion: documentación del proyecto.
